# NHANES Hypertension ML

Reproducible Python code for the study:

> **Explainable Machine Learning for Hypertension Prediction Using NHANES Data: Comparative Performance and Cross-Model SHAP Analysis**

This repository contains the data-download, data-preparation, machine-learning, explainability, and statistical-analysis code used in the study.

## Repository structure

```text
NHANES-Hypertension-ML/
├── README.md
├── requirements.txt
├── .gitignore
├── data/
│   ├── raw/                 # downloaded NHANES XPT files (not tracked)
│   └── processed/           # generated analysis dataset (not tracked)
├── figures/                  # generated PDF figures
├── results/                  # generated CSV results
└── src/
    ├── data.py
    ├── cekdata.py
    └── pemodelanhipertensi.py
```

## Dataset

The analysis uses NHANES 2021–2023 data files:

- `DEMO_L.xpt` — Demographics
- `BMX_L.xpt` — Body Measures
- `BPXO_L.xpt` — Blood Pressure
- `BPQ_L.xpt` — Blood Pressure Questionnaire

The raw NHANES files are downloaded automatically by `src/data.py` from the official CDC/NHANES data server.

Raw `.xpt` files and the generated processed dataset are intentionally excluded from Git tracking through `.gitignore`. This keeps the repository lightweight and allows the dataset to be regenerated from the source files.

## Variables

The final analytical dataset contains:

- `SEQN`
- `Age`
- `Gender`
- `Education`
- `Income_Poverty_Ratio`
- `Height`
- `Weight`
- `BMI`
- `Waist`
- `Hypertension`

`Hypertension` is derived from `BPQ020`, with:

- `1` = reported physician-diagnosed hypertension
- `0` = no reported physician diagnosis

The data-preparation script restricts the sample to adults, merges the four NHANES files by `SEQN`, retains valid `BPQ020` responses, renames the predictors, removes missing values in the analysis variables, and writes the processed dataset to:

```text
data/processed/dataset_hypertension.csv
```

## Analysis workflow

Run the scripts from the repository root in this order:

### 1. Download NHANES data

```bash
python src/data.py
```

This downloads the four NHANES `.xpt` files into:

```text
data/raw/
```

### 2. Prepare the analytical dataset

```bash
python src/cekdata.py
```

This merges the NHANES files and creates:

```text
data/processed/dataset_hypertension.csv
```

### 3. Run the modelling and explainability analysis

```bash
python src/pemodelanhipertensi.py
```

The modelling script performs data checks, train-test splitting, baseline model evaluation, hyperparameter tuning, SHAP analysis, bootstrap confidence intervals, DeLong ROC-AUC comparison, and anthropometric correlation analysis.

Generated figures are saved in:

```text
figures/
```

Generated result tables are saved in:

```text
results/
```

## Models

The analysis compares:

- Logistic Regression (LR)
- Random Forest (RF)
- Extreme Gradient Boosting (XGBoost)

The modelling workflow uses an 80/20 stratified train-test split with `random_state=42`.

Logistic Regression uses standardized numerical predictors, while the tree-based models use the original predictor scale.

Random Forest and XGBoost are tuned using grid search with 5-fold cross-validation and ROC-AUC as the optimization metric.

## Explainable AI

SHAP analysis is performed for the tuned Random Forest and XGBoost models.

The repository code generates:

- SHAP beeswarm plots
- SHAP bar plots
- SHAP waterfall plots
- Cross-model SHAP comparison

The cross-model analysis also evaluates agreement between feature-importance rankings.

## Statistical analysis outputs


## Reproducibility

Create a virtual environment before installing the dependencies:

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Then run the three scripts in the order shown above.

## Important notes

1. Run the commands from the repository root so that the relative paths resolve correctly.
2. The raw NHANES files are downloaded by the repository code and are not committed to GitHub.
3. The generated processed dataset is also not committed by default.
4. Figures and result CSV files are generated by the modelling script.
5. The analysis is intended to reproduce the computational workflow; it should not be interpreted as a survey-weighted population estimate unless the survey design is explicitly incorporated.
